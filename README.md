Heatshrink compressed bad apple video in 128x64 1bit.  
Requires I2C 128x64 1bit display. You can use different size or bit amount, but you need to download the original Bad Apple video and compress it with heatshrink. My params are  
W: 10 L:4 BUF: 2048.
Don't build in dev mode because even in release program takes almost all available space.
